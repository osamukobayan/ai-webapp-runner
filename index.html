生成AI Webアプリ実行器

生成AIが作成したHTMLを左側に貼り付けて「実行」を押すと、右側で動作を確認できます。ログイン不要・保存不要の授業向け構成です。

安全版の制限： 生徒が貼り付けたコードは、親ページから分離した iframe sandbox 内で実行します。 外部サイトへの通信、外部CDN・API、フォーム送信、埋め込みフレーム、ダウンロード等は原則として利用できません。 ページを再読み込みすると入力内容は消えます。個人情報・パスワード・APIキーは貼り付けないでください。
準備完了
HTMLコード HTML / CSS / JavaScript を1つにまとめて貼り付け
プレビュー 安全なサンドボックス内で実行
① 何が動く？ HTML、CSS、基本的なJavaScriptは動きます。ボタン、計算、クイズ、簡単なゲーム、画面切り替えなどの確認に向いています。
② 何が動かない？ Google Maps、外部API、CDN上のライブラリ、外部画像、外部フォントなど、インターネット通信が必要な機能は安全のため遮断しています。
③ データは保存される？ このページ自身は入力内容を保存しません。プレビュー側も同一オリジン権限を与えていないため、ブラウザ保存機能は基本的に利用できません。

GitHub Pages等で公開して使用できます。公開中はURLを知る人がアクセスできるため、この実行器自体にも生徒作品にも個人情報を含めない運用を推奨します。
